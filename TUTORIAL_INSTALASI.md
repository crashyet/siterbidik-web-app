# 📱 Tutorial Instalasi & Penggunaan SITERBIDIK

## 🎯 Tentang Aplikasi

**SITERBIDIK** adalah aplikasi yang dirancang khusus untuk membantu siswa meningkatkan kemampuan berbicara di depan publik (public speaking). Aplikasi ini menyediakan berbagai fitur pembelajaran, simulasi, dan evaluasi untuk mengembangkan keterampilan komunikasi Anda.

---

## 📥 Cara Download Aplikasi

Ikuti langkah-langkah berikut untuk mengunduh aplikasi SITERBIDIK:

1. **Buka link Google Drive** yang telah disediakan oleh admin atau guru Anda
2. **Cari file aplikasi** dengan nama `SITERBIDIK.apk`
3. **Klik tombol Download** pada file tersebut
4. **Tunggu proses download** hingga selesai (ukuran file sekitar 40 MB tergantung koneksi internet)

> [!TIP]
> Pastikan Anda memiliki koneksi internet yang stabil untuk menghindari kegagalan download.

---

## 🔧 Cara Install Aplikasi

Karena aplikasi SITERBIDIK belum tersedia di Google Play Store, Anda perlu mengizinkan instalasi dari sumber tidak dikenal. Berikut langkah-langkahnya:

### Langkah 1: Buka File APK
- Buka folder **Downloads** di perangkat Android Anda
- Cari dan **tap file `SITERBIDIK.apk`**

### Langkah 2: Izinkan Instalasi dari Sumber Tidak Dikenal

Jika muncul peringatan seperti:
```
"Install blocked" atau "Aplikasi dari sumber tidak dikenal"
```

Lakukan hal berikut:

1. **Tap "Settings" atau "Pengaturan"**
2. **Aktifkan opsi "Izinkan dari sumber ini"** atau **"Allow from this source"**
3. **Kembali ke halaman instalasi**

### Langkah 3: Install Aplikasi
1. **Tap tombol "Install"**
2. **Tunggu proses instalasi** (biasanya 10-30 detik)
3. Setelah selesai, **tap "Open"** atau **"Buka"**

> [!IMPORTANT]
> Fitur keamanan Android akan meminta izin ini untuk melindungi perangkat Anda. SITERBIDIK aman digunakan dan telah diverifikasi oleh sekolah/institusi Anda.

---

## 🔐 Cara Login

Setelah aplikasi terbuka, ikuti langkah berikut untuk masuk:

1. **Buka aplikasi SITERBIDIK** dari home screen atau app drawer
2. Pada halaman login, **masukkan kredensial Anda**:
   - **Username**: (diberikan oleh admin/guru)
   - **Password**: (diberikan oleh admin/guru)
3. **Tap tombol "Login"**
4. Jika data benar, Anda akan masuk ke **halaman utama aplikasi**

> [!WARNING]
> Jika Anda belum memiliki akun, silakan hubungi admin atau guru Anda untuk mendapatkan username dan password.

### Troubleshooting Login
- **Username/Password salah**: Periksa kembali kredensial Anda (perhatikan huruf besar/kecil)
- **Tidak bisa login**: Pastikan koneksi internet aktif
- **Lupa password**: Hubungi admin untuk reset password

## 🆘 Bantuan & Kendala

Jika Anda mengalami kendala seperti:

- ❌ Tidak bisa login
- ❌ Aplikasi error atau crash
- ❌ Data tidak muncul
- ❌ Fitur tidak berfungsi
- ❌ Lupa password

### Solusi:
1. **Restart aplikasi**: Tutup dan buka kembali aplikasi
2. **Periksa koneksi internet**: Pastikan internet aktif dan stabil
3. **Update aplikasi**: Pastikan menggunakan versi terbaru
4. **Hubungi Admin SITERBIDIK**:
   - WhatsApp: 0821-3514-2416
   - Atau hubungi guru/pembimbing Anda
